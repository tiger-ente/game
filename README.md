# Privacy Policy

This game and related browser applications respect user privacy and are designed to collect as little data as possible.

No personally identifiable information such as names, email addresses, passwords, payment information, or personal documents is collected by the game itself.

The applications may store limited local data inside the user's browser in order to provide core functionality and improve the user experience. This may include:

* highscores
* game progress
* gameplay statistics
* playtime information
* user settings and preferences

This information is typically stored locally on the user's device and is not used to personally identify users.

Some games or applications may use anonymous analytics services to better understand general gameplay behavior, technical performance, stability issues, or feature usage. These analytics are used solely for improving the applications and user experience.

No personal communication data is collected.

No financial or payment data is collected.

No authentication credentials such as passwords or PINs are collected.

The applications are not intended to sell personal data to third parties.

Third-party services used by browser platforms, analytics providers, or hosting services may process limited technical information such as browser type, device information, or anonymous usage statistics according to their own privacy policies.

By using these applications, users agree to this privacy policy.

This privacy policy may be updated in the future if features or services change.
